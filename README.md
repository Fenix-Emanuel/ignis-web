# Ignis Studio · theignisstudio.com

Web oficial de Ignis Studio (español / inglés). HTML, CSS y JavaScript puros, publicada con GitHub Pages.

- `index.html`: toda la web (textos ES/EN, fuego de partículas, proceso con scroll y el bot Brasa).
- `assets/`: logo, favicon e imagen para compartir.
- `CNAME`: dominio propio.

Datos del bot Brasa (WhatsApp, correo, Instagram): busca `const CONTACTO` en `index.html`.
